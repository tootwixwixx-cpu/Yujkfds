# Atomware Rivals

Universal high-performance script suite for Rivals (Roblox).

## Features
- **Desktop PC UI**: Obsidian cyberpunk theme with sidebar navigation, responsive dual-column cards, and widget controls.
- **Mobile Touch UI**: Adaptive mobile touch layout with floating toggle pill and responsive widgets.
- **Mobile Lite UI**: Lightweight high-fps touch mode optimized for lower-end devices.
- **Modular Feature Engines**:
  - Combat (Silent Aim, Triggerbot, Ragebot, Evasion, Visualizers, Exploits)
  - Visuals (ESP, Box, Tracers, Sensors, Chams)
  - Movement (Speed, Auto-Strafe, Movement Recorder, Noclip, Fly)
  - World (Lighting, Shaders, Custom Skyboxes, SunRays)
  - Cosmetics Subsystem (Skins, Wraps, Charms, Finishers)
  - Misc & Spoofing (Staff/Dev Detector, Profile & Rank Spoofing, Auto-Queue)
  - Anticheat Emulator & Client Guard
